# דיאגנוז פרו (Diagnose Pro)

אפליקציית אבחון OBD2 לרכב, בחינם. אין בה מנוי, פרסומות או חשבון, והיא לא צריכה הרשאת אינטרנט.
האפליקציה מתחברת למתאם ELM327 בבלוטות׳ (קלאסי או BLE), קוראת נתוני מנוע חיים וקודי תקלה, ויכולה
למחוק קודים כדי לכבות את נורית Check Engine. יש תמיכה מלאה בעברית ובאנגלית.

## התקנת קובץ ה-APK בטלפון

בתיקייה `release` יש שני קבצים:
`DiagnosePro-release.apk` (מומלץ, גרסת שחרור חתומה, כ-2.5MB) ו-`DiagnosePro-debug.apk` (גרסת פיתוח).
הם חתומים במפתחות שונים, ולכן **צריך להסיר אחד לפני שמתקינים את השני**.

1. העתיקו את קובץ ה-APK לטלפון, או הורידו אותו ישירות בטלפון.
2. פתחו את הקובץ. אנדרואיד יבקש לאשר **התקנת אפליקציות לא מוכרות** עבור האפליקציה שבה פתחתם אותו
   (קבצים, Chrome וכו׳). אשרו, חזרו אחורה והקישו על **התקנה**.
3. אם Play Protect מזהיר על מפתח לא מוכר, הקישו **פרטים נוספים ← להתקין בכל זאת**
   (הקובץ חתום במפתח debug).
4. נדרש אנדרואיד 8.0 ומעלה.

## צימוד המתאם

1. חברו את ה-ELM327 לשקע ה-OBD2 שמתחת להגה, והעבירו את ההצתה למצב **ON** (או התניעו).
2. **מתאם בלוטות׳ קלאסי** (רוב המתאמים הזולים): בהגדרות הטלפון ← בלוטות׳, צמדו את המכשיר
   (השם בדרך כלל OBDII,‏ ELM327 או V-LINK). הקוד הוא בדרך כלל `1234` או `0000`.
3. **מתאם BLE** (כמו Vgate iCar Pro BLE או OBDLink CX): לא צריך צימוד. השתמשו בכפתור **חיפוש** באפליקציה.
4. באפליקציה, הקישו על מצב החיבור בראש המסך, אשרו את הרשאת הבלוטות׳ ובחרו את המתאם.
   מכשירים שנראים כמו מתאם OBD מסומנים.

אין לכם מתאם? בחרו **מצב הדגמה** כדי לנסות את כל המסכים עם רכב מדומה.

## איך משתמשים בכל תכונה

- **לוח מחוונים:** מדים חיים כמו סל״ד, מהירות, טמפרטורות, עומס, MAF, MAP, תיקוני דלק, חיישני חמצן ומתח.
  מוצגים רק נתונים שהרכב שלכם תומך בהם. ערך חריג נצבע באדום. דרך **בחירת מדים** אפשר לבחור ולסדר את המדים, והבחירה נשמרת לכל רכב.
- **קודי תקלה ← קריאת קודים:** מציג קודים שמורים, ממתינים וקבועים, את מצב נורית Check Engine, ואיזו יחידת בקרה דיווחה על כל קוד.
- **הקשה על קוד:** תיאור בעברית, סיבות אפשריות, רמת חומרה ומה לבדוק. לקודים ייחודיים ליצרן יש כפתור חיפוש ברשת.
- **מחיקת קודים (Mode 04):** שני אישורים. הקודים נשמרים בהיסטוריה לפני המחיקה, ואחריה הקודים נקראים שוב כדי לבדוק אם התקלה חזרה.
  חשוב: המחיקה לא מתקנת את התקלה, והיא מאפסת את בדיקות המוכנות, כך שהרכב עלול להיכשל בטסט עד שייסע מספיק.
- **שיתוף דוח:** כטקסט או כ-PDF, בעברית או באנגלית.
- **כלים** (אייקון מפתח הברגים בלוח המחוונים): Freeze Frame, בדיקות מוכנות ("מוכן לטסט"), פרטי רכב ופענוח מספר שלדה,
  תוצאות Mode 06, הערכת צריכת דלק ומדידת 0-100 קמ״ש.
- **גרף חי:** עד 4 ערכים בו זמנית, עם השהיה, הגדלה וייצוא ל-CSV.
- **היסטוריה:** סריקות קודים, כולל השוואה לסריקה הקודמת, ונסיעות מוקלטות עם סיכום, גרפים וייצוא ל-CSV. מקליטים נסיעה מלוח המחוונים דרך **הקלטת נסיעה**.
- **הגדרות:** שפה (עברית, אנגלית או לפי המכשיר), יחידות מידה, קצב קריאה, התחברות אוטומטית, מסך דולק, ערכת נושא וקונסולת מפתחים.

**מגבלות:** OBD2 גנרי קורא רק את מערכות המנוע והפליטה. מערכות ABS, כריות אוויר ותיבת הילוכים דורשות בדרך כלל כלי ייעודי ליצרן.
האפליקציה רק קוראת נתונים. הפקודה היחידה שמשנה משהו ברכב היא מחיקת קודים (Mode 04).
**אל תשתמשו באפליקציה בזמן נהיגה.**

## בנייה מקוד המקור

נדרשים JDK 17 ומעלה ו-Android SDK עם platform 34 ו-build-tools 34.
